A C++17 header-only templated library for geometry and spatial-audio
primitives:

- Vector
- Point
- Plane
- Ray
- Ellipse / Ellipsoid
- Colour
- Matrix mixer (summing matrix, SIMD)
- Timer
- Random sampling
- SOFA axis/direction conventions and physical constants
- and more to come

This library uses [Google Highway](https://github.com/google/highway) for
SIMD optimisations.

## Installation

Simply run:

```sh
git clone --recurse-submodules https://github.com/RoBr-01/RTB-Robins-ToolBox.git
```

Or add it to your project as a git submodule.

## CMake set-up

Purely as an example, adapt to your own needs as necessary:

```cmake
add_subdirectory(whereveritis/RTB)
target_link_libraries(${PROJECT_NAME} PRIVATE RTB)
```

`RTB` is defined as an `INTERFACE` library, so its include directory and
Highway dependency are propagated automatically — no need to add the
include path yourself.

## Usage

To get started, either include the specific module you need:

```cpp
#include <RTB/Vector.hpp>
```

Or include everything:

```cpp
#include <RTB/RTB.hpp>
```

Then you can do:

```cpp
RTB::Vector<float, 3> v{1.0f, 2.0f, 3.0f};
v.normalizeInPlace();
```

And so on.

## Building

Configure and build with a preset (see
[CMakePresets.json](CMakePresets.json)):

```sh
cmake --preset test-debug
cmake --build --preset test-debug
```

Available presets: `dev`, `lib-debug`, `lib-release`, `test-debug`,
`test-release`, `bench-debug`, `bench-release`, `examples-debug`,
`examples-release`.

Tests, benchmarks, examples, and the `dev/` playground are only built when
RTB is the top-level project, and are each gated by their own option
(`RTB_ENABLE_TESTING`, `RTB_ENABLE_BENCHMARK`, `RTB_ENABLE_EXAMPLES`,
`RTB_ENABLE_DEV`) — the presets above set the relevant ones for you.

## Running tests

This project uses GoogleTest, discovered individually via
`gtest_discover_tests`:

```sh
cmake --preset test-debug
cmake --build --preset test-debug
ctest --test-dir build/test-debug
```

Run a single test binary directly, or filter with gtest's `--gtest_filter`:

```sh
./build/test-debug/bin/Vector_test --gtest_filter=VectorTest.DotProduct
```

## Generating documentation

Doxygen documentation can be generated by running:

```sh
doxygen
```

In the root of the project. The `docs/` folder is automatically generated.
